Get started with the Gemini API in Go

Set up your environment, install the official generative-ai-go SDK, configure authentication, and run your first model inference in under 2 minutes.

Go 1.21+ verified Official Google SDK gemini-1.5-flash / pro ready
01

Initialize a Go module

Create a clean directory and scaffold standard module manifests

CLI COMMAND
bash — terminal 
$ mkdir -p ~/gemini-go && cd ~/gemini-go
$ go mod init gemini-go
02

Install the Gemini SDK and Google API dependencies

Pull the official Generative AI engine client and runtime options

DEPENDENCIES
go get — dependencies 
$ go get github.com/google/generative-ai-go/genai
$ go get google.golang.org/api/option
$ go get google.golang.org/api/iterator
token genai

Provides core client lifecycle, GenerativeModel, and prompt constructors.

Configures API authentication tokens, endpoints, and HTTP telemetry client options.

stream iterator

Handles streaming response chunks and continuous token iterations gracefully.

03

Export your API key

Expose credential variable to your environment shell

SECURITY
env — auth 
$ export GEMINI_API_KEY="your-actual-api-key"
security

Security Warning & Secret Management

Never commit your API key to public repositories, source files, or build containers. In production, load tokens via secret managers (Secret Manager, Vault) or inject via secure runtime environment vars.

Grab a free developer API key in Google AI Studio open_in_new
04

Save your code into main.go, then run it

Full runnable implementation of client configuration and token generation

GO RUN
gemini-1.5-flash 
package main

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/google/generative-ai-go/genai"
    "google.golang.org/api/option"
)

func main() {
    ctx := context.Background()
    client, err := genai.NewClient(ctx, option.WithAPIKey(os.Getenv("GEMINI_API_KEY")))
    if err != nil {
        log.Fatalf("Failed to create client: %v", err)
    }
    defer client.Close()

    model := client.GenerativeModel("gemini-1.5-flash")
    resp, err := model.GenerateContent(ctx, genai.Text("Explain quantum computing in one sentence for a developer."))
    if err != nil {
        log.Fatalf("Error generating content: %v", err)
    }

    for _, cand := range resp.Candidates {
        if cand.Content != nil {
            for _, part := range cand.Content.Parts {
                fmt.Printf("%v\n", part)
            }
        }
    }
}
$ go run main.go
