Quickstart: Text Generation with Go

Generate content in under 5 minutes using the official github.com/google/generative-ai-go/genai package for Go 1.21+.

account_tree Code Walkthrough & Concepts

1

Initialize Client with API Credentials

The genai.NewClient(ctx, option.WithAPIKey(apiKey)) constructs an authenticated RPC client. Always call defer client.Close() immediately after verifying that err == nil to ensure underlying connection pools close gracefully.

2

Instantiate the Target Generative Model

Use client.GenerativeModel("gemini-2.5-flash") for high-frequency low-latency generation. You can configure execution parameters directly on the model instance like model.SetTemperature(0.7) before calling generation routines.

3

Generate & Iterate Content Candidates

model.GenerateContent(...) accepts variadic genai.Part values. The response structure contains one or more Candidate instances containing generated text fragments.
